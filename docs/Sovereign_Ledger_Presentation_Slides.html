Military-Grade Security

OWASP-Compliant Zero-Trust Architecture

🔐 Authentication — Argon2id

  • Memory cost 19,456 KiB — GPU/ASIC cracking exceeds $20,000/hour
  • Cloud brute-force: $150+ for a single 6-month attempt
  • 3+ seconds per hash verification — rate-limiting by design

🍪 Session Management — Signed Cookies

  • itsdangerous TimedSerializer with HMAC-SHA256 signatures
  • SameSite=Strict — blocks CSRF via cookie submission
  • Secure flag — HTTPS-only transport in production

🛡️ CSRF Protection — Per-Session Tokens

  • Cryptographically random token per session
  • X-CSRF-Token header required for all mutations
  • Token rotation on authentication events

👥 Access Control — Role-Based

  • Admin: full system access (account mgmt, period close, user admin)
  • Accountant: entry posting + reporting only (no account modification)
  • Boundary enforcement at dependency injection level
